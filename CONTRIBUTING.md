# Contributing Guide

DO NOT PUSH TO MAIN unless code is stable and production ready
Use branches to develop your code. Name branches based on what
you are doing

Using Python as our backend, use the venv that will be created.

Using React.ts as our frontend. Use PascalCase for files,
camelCase for function names.

Commit Messages should be clear, descriptive, and concise

# Prettier Instructions

Just make sure you have the Prettier extension enabled so that
it auto corrects your spacings/wordings through the .prettierrc
file

If using VSCode, you can install Prettier using the VSCode
Marketplace.

Have "Format on Save" enabled so Prettier can do its thing.

Make sure Prettier formatted your code before pushing
